# MCP 是什么

MCP（Model Context Protocol）是一套让模型安全调用外部能力的协议。它把系统分成三个角色：

- **Host**：承载模型的程序，例如 Claude Code、知源、你自己的客户端。
- **Client**：Host 内部与某个服务器保持一条连接的组件，负责协议握手与工具调用。
- **Server**：对外提供工具（tools）、资源（resources）和提示（prompts）的进程。

服务器可以用 stdio 启动（本地进程），也可以用 Streamable HTTP 暴露（远程服务）。对学习来说，stdio 最简单：客户端拉起一个子进程，通过标准输入输出交换 JSON-RPC 消息。

一次工具调用大致经过：

1. 客户端发送 `initialize`，双方交换协议版本与能力；
2. 客户端 `tools/list` 拿到工具名、描述与参数 schema；
3. 模型决定调用某个工具，客户端发送 `tools/call`；
4. 服务器执行并把结果作为内容块返回；
5. 模型基于结果继续回答。

关键点：**工具描述就是模型的说明书**。名字、描述、参数 schema 写不清楚，模型就会乱调；错误信息写不清楚，模型就无法自我修正。
